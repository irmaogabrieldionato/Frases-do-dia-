Política de privacidade

7-Note Musical Game · Atualizado em 21/11/2026.

Esta política descreve a versão 1.4.0 do jogo para navegador, Android, Android TV/TV Box, Windows e iOS.

Dados armazenados

O jogo armazena no próprio aparelho as fases, recordes, derrotas, acertos, pontuação, preferências de som e melodias criadas. Esse armazenamento utiliza recursos locais do navegador incorporado ao aplicativo.

Não pedimos nome, telefone, e-mail, localização, contatos, câmera, fotos nem acesso ao microfone. A versão distribuída neste projeto não tem cadastro nem sincronização entre aparelhos.

Transmissão e terceiros

Na implementação atual não existe conta, analytics, SDK de publicidade ou conexão com um servidor para enviar os dados do jogador. O áudio é sintetizado localmente. A tela de intervalo exibida após duas derrotas é apenas uma demonstração identificada e não exibe anúncios pagos ou personalizados.

Se forem adicionados anúncios reais, analytics ou sincronização, esta política deverá ser atualizada antes de a nova versão ser disponibilizada.

Como apagar seus dados

Dentro do jogo, abra Ajustes → Apagar todos os dados e recordes. A desinstalação do aplicativo também pode eliminar os dados locais conforme o comportamento do sistema operacional. Apagar o armazenamento do navegador pode remover o progresso da versão web.

Uso por crianças

O jogo é um desafio de memória e percepção musical. Nenhum perfil de criança é solicitado. Antes de distribuir versões com anúncios reais para menores, serão necessárias avaliações adicionais de classificação etária, privacidade, consentimento e políticas de cada loja.

Alterações nesta política e contato

Alterações relevantes serão publicadas nesta página. Para dúvidas sobre o projeto ou dados locais, consulte a página pública do repositório: 7-Note Musical Game no GitHub.

Observação para publicação em lojas: o responsável pela conta deverá confirmar uma forma de contato oficial, preencher as declarações de privacidade e fornecer o endereço público desta política na ficha da loja.
